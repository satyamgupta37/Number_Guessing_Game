🎯 Number Guessing Game

📌 Project Description
The Number Guessing Game is a simple Python-based game in which the computer randomly selects a number between 1 and 100. The player must guess the correct number within 7 attempts.
After each guess, the game provides hints to help the player find the correct number. It tells the player whether their guess is too low or too high.

🎮 Features
•Generates a random number between 1 and 100.
•Gives the player 7 attempts to guess the number.
•Provides hints if the guessed number is too high or too low.
•Checks whether the user enters a valid number.
•Displays a congratulatory message when the correct number is guessed.
•Shows the correct number if the player fails to guess it within 7 attempts.
•Uses a lambda function to check the user's guess.

🛠️ Technologies and Concepts Used
Programming Language: Python
Module: random
Functions: def
Conditional Statements: if, else
Recursion: Repeats the guessing process by calling the function again.
Lambda Function: Checks whether the guess is correct, too low, or too high.
Exception Handling: try and except
User Input and Output: input() and print()

▶️ How to Run the Project
Step 1: Install Python on your computer.
Step 2: Download or clone this repository.
Step 3: Open the project folder in VS Code or another Python editor.
Step 4: Run the following command in the terminal:
python index.py
Step 5: Follow the instructions displayed on the screen and start guessing the number.
